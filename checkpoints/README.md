# Trained checkpoints

Trained model checkpoints (one per architecture x dataset combination, ~100-300MB each)
are not committed to this git repository. Once published, they will be made available as
a separate download (GitHub Release or Zenodo record) linked here.

In the meantime, train each architecture yourself following the "Train an architecture"
section of the top-level `README.md` -- every config used to produce the paper's results
is included under `configs/`.
